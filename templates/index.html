Reinforcement Learning Architecture & Technical Assessment

1. Data Layer & Preprocessing Module

Loads 4-channel MRI modal volumes (T1, T1ce, T2, FLAIR) from BraTS 2D slice dataset. Extracts ground-truth lesion masks and derives ground-truth bounding box coordinates [xmin, ymin, xmax, ymax]. Filters slice samples containing valid lesion regions for training and evaluation.

2. Reinforcement Learning Environment (BrainLesionEnv)

Framed as a Gym-style sequential decision process where the agent adjusts its view window bounding box across 7 discrete actions: Move Left, Move Right, Move Up, Move Down, Zoom In (Scale Down Box), Zoom Out (Scale Up Box), and Trigger (Stop/Commit Prediction). Calculates ROI patch crops dynamically resized to 64x64x4 alongside normalized spatial coordinates.

3. Neural Network Feature Extractor & Q-Network (model.py)

Uses a 3-layer Convolutional Neural Network (CNNEncoder) with BatchNorm and ReLU to compress the 4-channel ROI patch into a 256-dim embedding, concatenated with normalized bounding box spatial features [x1, y1, x2, y2, step/max_steps] into a Q-network estimating action values Q(s, a).

4. DQN vs Double-DQN (DDQN) Overestimation Analysis

Standard DQN uses max Q(s', a') over the target network, causing overestimation bias on noisy MRI slices. Double-DQN decouples action selection (via online network) from value evaluation (via target network), leading to more stable Q-value convergence and higher Dice/IoU scores.
